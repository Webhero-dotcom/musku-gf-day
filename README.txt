FOR MUSKU v2 — how to launch her universe 💗
=============================================

WHAT THIS IS
One single webpage (index.html) + her photos. No installs, no accounts.
Open index.html in any browser to test it right now.

DEPLOY (GitHub Pages — 5 minutes, you've done this before)
1. github.com → New repository → name it: for-musku → Public → Create
2. "uploading an existing file" → drag EVERYTHING inside this folder
   (index.html + the images folder + music.mp3 if you add one) → Commit
3. Settings → Pages → Branch: main, folder: / (root) → Save
4. Wait ~2 min → your link: https://YOURUSERNAME.github.io/for-musku/
5. Send her the link on Aug 1. Done. Tears guaranteed.

THE GATE
Password = anything starting with "musk" (musku, Muskan, MUSKU… all work).
After 1 wrong try a cute hint appears.

EDIT ANYTHING
Open index.html → find the "💗 EDIT ME" CONFIG block near the bottom.
Everything personal is there in plain text:
  - typerLines ......... rotating lines under her name
  - quiz ............... 8 questions (change q/a/c — c = correct index)
  - wheel .............. the 8 date-night wheel slices
  - cookies ............ 18 fortune-cookie lines
  - skyLabels .......... the 12 star-constellation memories
  - openWhen ........... the 3 "Open when…" letters (the deep ones)
  - reasons ............ the 12 lily reasons
  - letter ............. the big final letter
Save the file, refresh, done.

MUSIC (optional, recommended)
Drop a file named exactly:  music.mp3  into this folder next to index.html.
A 🎵 button appears automatically top-right. No file = no button = no error.
(Use a soft romantic instrumental. Keep it under ~5 MB for fast loading.)
